Glossary

Terminology and abbreviations used throughout the PlateShare project.

Administrator
An authorized user responsible for managing accounts, permissions, and platform operations.
Algorithm
A defined sequence of instructions used to solve a problem or perform a computational task.
API (Application Programming Interface)
A set of protocols and functions that enables communication between software applications.
Authentication
The process of verifying the identity of a user attempting to access the platform.
Authorization
The process of determining which resources and actions a user is permitted to access.
Backend
The server-side components of an application responsible for processing requests, executing business logic, and managing data.
Business Donor
A restaurant, grocery store, catering company, or other business that provides surplus food for donation.
Claim Status
The current state of a donation claim, such as pending, approved, completed, or canceled.
CRUD (Create, Read, Update, Delete)
The four fundamental operations used to manage information within a database.
Database
An organized collection of information used to store and retrieve application data.
Database Schema
The structure of a database that defines its tables, fields, relationships, and constraints.
Delivery Status
The current stage of a food delivery, such as awaiting pickup, in transit, delivered, or canceled.
Donation Claim
The reservation of an available food donation by a recipient organization.
Donation History
A record of previous donations and their associated claims, pickups, and deliveries.
Donation Listing
A record of available surplus food containing information such as food type, quantity, location, and pickup availability.
Donor
An individual or organization that provides surplus food for redistribution.
End User
An individual who directly interacts with the PlateShare platform, including donors, recipient organizations, and volunteers.
Expiration Date
A date associated with a food product that may be used when evaluating its suitability for donation, alongside applicable food safety requirements.
Food Bank
A charitable organization that collects, stores, and distributes food to hunger-relief programs and communities.
Food Insecurity
Limited or uncertain access to sufficient and nutritious food necessary for an active and healthy life.
Food Rescue
The collection and redistribution of edible food that would otherwise be discarded.
Food Safety
Practices and procedures intended to prevent contamination and foodborne illness during food preparation, storage, transportation, and distribution.
Food Waste
Food that is discarded or otherwise removed from the human food supply.
Frontend
The user-facing portion of an application through which users interact with its features and functionality.
Geolocation
The identification of a geographical location using information such as addresses, coordinates, or device location data.
Git
A distributed version control system used to track changes to source code and support collaborative software development.
GitHub
An online platform for hosting Git repositories, managing source code, and collaborating on software projects.
GitHub Pages
A static website hosting service provided by GitHub that publishes website files directly from a repository.
GUI (Graphical User Interface)
A visual interface that allows users to interact with an application through elements such as buttons, menus, and forms.
Matching Algorithm
A procedure used to identify suitable recipient organizations or volunteers based on donation details and relevant eligibility criteria.
MFCD (Major Functional Component Diagram)
A diagram illustrating the primary functional components of a system and the relationships between those components.
Nonprofit Organization
An organization that operates to support a charitable or public purpose rather than distribute profits to private owners.
Notification
An electronic alert that informs users of relevant events, available donations, assignments, or status changes.
Notification Algorithm
A procedure that determines which users should receive notifications based on relevant events, user roles, and donation information.
Pickup Location
The designated physical location where a volunteer or recipient organization collects a food donation.
Pickup Window
The designated period during which a food donation is available for collection.
PlateShare
A proposed centralized food donation platform designed to connect businesses with surplus food, charitable organizations, and volunteer drivers to reduce food waste and improve food accessibility.
Prototype
A preliminary implementation of a proposed system used to demonstrate, test, and evaluate its primary functionality.
RBAC (Role-Based Access Control)
A security approach that assigns permissions to users based on their designated roles within a system.
Recipient Organization
A food bank, shelter, nonprofit organization, or other charitable institution that accepts food donations for redistribution.
REST API
An application programming interface that follows Representational State Transfer architectural principles to enable communication between software components.
Scalability
The ability of a system to accommodate increasing numbers of users, transactions, and data without unacceptable reductions in performance.
SQL (Structured Query Language)
A programming language used to create, retrieve, modify, and manage information within relational databases.
Stakeholder
An individual or organization that has an interest in or is affected by the development and operation of the PlateShare platform.
Surplus Food
Excess food that is no longer needed by its original owner but remains suitable for consumption or donation.
Transportation Logistics
The planning and coordination of food collection, transportation, and delivery between donors and recipient organizations.
UI (User Interface)
The collection of visual and interactive elements through which users communicate with a software application.
UX (User Experience)
The overall experience of a user interacting with an application, including its usability, accessibility, and efficiency.
Volunteer Assignment
The process of connecting an eligible and available volunteer with a food pickup and delivery task.
Volunteer Assignment Algorithm
A procedure used to identify and assign suitable volunteers to delivery tasks based on factors such as availability, location, and delivery requirements.
Volunteer Driver
An individual who voluntarily transports donated food from participating businesses to recipient organizations.
WBS (Work Breakdown Structure)
A hierarchical division of project work into smaller, manageable tasks and deliverables used for project planning and organization.
Wireframe
A simplified visual representation of an application's interface used to demonstrate its layout, navigation, and functionality before implementation.
